# BA Kit examples

The [CR-001 Appointment Scheduling example](CR-001/README.md) is documentation-only. It illustrates an incomplete input, gaps, Human decisions, Business Rules, an SRS excerpt, and a contract-valid handoff fixture.

Do not feed approved example outputs into a fresh-session acceptance run. The agent should discover gaps from the allowed input itself. Examples illustrate contracts and decisions; they are not golden transcripts or mandatory templates.

For acceptance cases, see [acceptance.yaml](../acceptance.yaml) and [the CR-001 acceptance probes](../../../ba-workflow/evals/cr001-acceptance.md).
