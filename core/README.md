# Core capabilities

Core is a composition/classification layer, not a fourth role kit and not a directory for physical skills. The skills remain canonical at repository root.

The initial manifest includes `verification-before-completion` (role-neutral evidence gate) and `codebase-discovery` (brownfield evidence proven in BA and intended for later engineering/test work). The latter's cross-kit reuse remains future validation because Dev/Test kits are not implemented here. Kit manifests reference these names; they do not copy their directories.
