## Tribal knowledge gaps

- The supported Windows Git checkout settings needed for Test package authority validation are not in the install guide.
- A reader must know to discover Dev pages outside the main indexes.
- A reader must know that OPTIONAL_DEGRADED is a conformance projection status distinct from Test Doctor DEGRADED and Suite PASS.
- A reader must search tooling/PACKAGING.md to interpret package authority error codes; recovery steps are not mapped to each code.
- A reader must search the Vietnamese suite contract to find the mandatory public conformance command.

No role guide tells an operator to bypass a Human Gate or treat generated evidence as approval. The gaps concern locating the right guide and recovering from a normal failure.
